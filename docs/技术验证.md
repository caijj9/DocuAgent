## 四、示例 3 · 工具调用

**结论**：✅ 通过 —— **Java 方法确实被执行了**（不是模型自己编的）

```
DEBUG o.s.a.m.tool.DefaultToolCallingManager   : Executing tool call: currentTime
DEBUG o.s.ai.tool.method.MethodToolCallback    : Starting execution of tool: currentTime
>>> [Java 方法真的执行了] currentTime(city=北京)
DEBUG o.s.ai.tool.method.MethodToolCallback    : Successful execution of tool: currentTime
DEBUG o.s.a.t.e.DefaultToolCallResultConverter : Converting tool result to JSON.
【示例3·工具调用】模型回答=北京现在的时间是2026年10月14日11点18分。
```

### 从日志逐行读出来的链路

```
① 模型提出调用请求     Executing tool call: currentTime
② Java 方法开始执行     Starting execution of tool: currentTime
③ Java 方法真的跑了     >>> [Java 方法真的执行了] currentTime(city=北京)   ← 我们自己打的那行
④ 方法执行成功         Successful execution of tool: currentTime
⑤ 结果转 JSON 回传      Converting tool result to JSON.
⑥ 模型据此作答         北京现在的时间是2026年10月14日11点18分
```

### 为什么这能证明"工具真的被调了"

问的是「**北京现在几点**」——**模型自己不知道当前时间**（它只有训练数据，没有实时时钟）。
但回答出来的时间和真实时间**完全一致** → 这个时间只可能来自 Java 方法 `currentTime()` 的返回值。

**判断标准**：只有模型的回答、没有 `>>>` 那行 → **不算通过**（可能模型在瞎编）。
