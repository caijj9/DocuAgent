# 参考资料与引用范围

本工程使用Spring AI、Spring Boot、MyBatis-Plus及Apache Tika等依赖，具体版本以pom.xml为准。

## 官方资料

- [Spring AI参考文档](https://docs.spring.io/spring-ai/reference/)：OpenAI兼容模型、ChatClient、Embedding、工具调用、模型观测与向量库API。
- [Spring Boot参考文档](https://docs.spring.io/spring-boot/3.5/reference/)：配置、Web MVC与应用启动。
- [硅基流动文档](https://docs.siliconflow.cn/)：OpenAI兼容请求与模型服务。
- [Apache Tika](https://tika.apache.org/)：课件文本提取。
- [MyBatis-Plus](https://baomidou.com/)：Mapper、主键与逻辑删除。

## 本地调研过的开源项目

- OOMEcho：[rag-knowledge-system](https://github.com/OOMEcho/rag-knowledge-system)，课程知识库上传、检索与问答的设计参考；早期另有独立本地适配目录。
- OOMEcho：[rag-knowledge-web](https://github.com/OOMEcho/rag-knowledge-web)，知识库问答交互调研。
- HeyZhuang：[SpringAI-Nexus](https://github.com/HeyZhuang/SpringAI-Nexus)，Spring AI示例调研。

以上链接来自本机参考仓库的Git origin。DocuAgent不是把这些仓库整体复制后的发行版；当前课程领域模型、检索校验、业务闭环、评测脚本和本轮静态HTML/CSS/JavaScript在本工程实现。它们未作为本工程源码依赖引入。

## 评测资料

- 编译原理三份课件来自用户本机，私人原文件、提取语料、原向量和实验数据库不纳入Git；评测结果保留必要的来源片段以支持本地审查。
- `eval/fixtures`中的TXT为明确标注的合成隔离/流程资料，不冒充用户的正式课件。
- 自动规则结果与人工核对范围分别注明，失败不删除；成本采用显式测算单价，不当作供应商账单。
