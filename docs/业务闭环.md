# 段2：课程学习业务闭环

沿用 Java17、Boot3.5.13、SpringAI1.1.8、MP3.5.17；使用现有MySQL和Redis。HTTP仍返回200，业务成功看`code=0`，失败看非零业务码。

## 启动和数据库

环境变量AI_API_KEY必须可用。Redis默认127.0.0.1:6379，可通过REDIS_HOST、REDIS_PORT覆盖。会话数据只使用`docuagent:*`前缀，不操作CampusMart的键。

现有数据库补充了answer_record.hit_points、missed_points两个TEXT字段，用来保存评分要点JSON，保证重试返回原始完整结果。
`sql/init.sql`的CREATE TABLE、ER文档与本机库已同步。旧库可运行`node scripts/migrate-stage2.cjs`，脚本先备份且只补缺失字段；不会清空原表。

```powershell
$env:JAVA_HOME='E:\jdk17'
mvn test
mvn package -DskipTests
java -jar target/DocuAgent-0.0.1-SNAPSHOT.jar
```

打包前停止旧JAR服务，避免Windows锁住运行包。端口18081。

## 接口

### 答疑

```text
POST /qa/ask
{"question":"词法分析器有什么作用？","courseId":1,"sessionId":null}
```

返回`answer、references、rewrittenQuestion、sessionId`。references含index、chunkId、documentId、documentName、snippet、score。
检索为空直接拒答，不调用回答模型。非空时也不能凭相似度就宣称有答案；模型须判断原文是否支持答案，资料外问题明确拒答并返回空引用。
引用编号先验证范围，再按首次出现顺序重新编号；没有有效引用不能当作正常资料内回答。
独立复核仅看到实际返回的引用原文，检查是否支持全部结论；不通过最多修正一次，仍不通过就拒答。该机制减少错误，不能保证所有模型结论都正确，仍需人工核对。

### 出题

```text
POST /question/generate
{"courseId":1,"count":5,"type":"mixed","keyword":"词法分析器"}
```

count为1到10；type为single_choice、short_answer、mixed。mixed数量大于1时包含两种题型，分别调用模型生成，避免不同字段结构互相污染；任一批失败都不入库。
先校验全部题目，再一次事务保存：题量、题型、题干、选项、正确标签、评分要点、长度、重复题干、来源集合都要通过。
纯文本选项由服务器按原顺序补A/B标签；已有标签必须连续，不能自动重排来改变答案。出题回复不暴露参考答案和评分要点，避免作答前泄题。
来源原文直接从服务器按已校验sourceChunkId取出，不相信模型复制或改写的摘录。另一次独立调用检查题目、答案、全部评分要点以及单选唯一性；任一不通过则整批失败、不写question。
简答题至少两个评分要点，才能验证部分正确。内容复核不是数学证明，题目可用率仍需逐题检查。

**第一版单选范围**：使用二选一判断式（满足至少2个选项的约定）。模型从服务器提供的课件原文事实ID中选材；服务器构造肯定/否定陈述与“正确/错误”互斥选项，并随机安排真假与答案位置。模型不能擅自修改事实、指定答案或把四个都成立的选项当单选。
较开放的四选项生成曾在真实验收中反复出现多解，未作为本版可用能力交付；保留了盲审和拒绝逻辑，后续要升级需重新验证，不宣称已实现可靠的任意四选项出题。
简答题仍由模型生成，并通过格式、来源与独立内容复核；不合格最多修正一次，仍失败就整批拒绝入库。

### 提交答案

```text
POST /answer/submit
{"questionId":11,"userAnswer":"A","durationMs":1200,"requestId":"unique-request-001"}
```

requestId非空，最多64个字母、数字、短横线或下划线。同一次请求重发必须保持questionId、userAnswer、durationMs一致。
返回score、maxScore、isCorrect、comment、hitPoints、missedPoints、answerRecordId、questionId。

- 单选题本地比较答案标签，正确10分、错误0分，不调用模型；日志标记`modelCalls=0`。
- 简答题模型逐项给出用户答案中的原文证据或空串；服务器检查非空摘录确实存在于用户答案，再按命中要点数/总数×10计算分数，保留两位。只接受裸的true/false容易把参考答案误判成用户已答到，因此没有采用。
- 格式、编号或证据不合法时不写answer_record，也不修改错题。
- 昂贵的模型调用在事务外；事务内锁题目、再次查requestId、插答题记录、累计错题。唯一索引兜底并发重复请求；同requestId不同内容报1104。
- 并发首发简答题仍可能发生重复模型计算，但只允许一个结果和一次错题累计提交，不宣称外部调用严格恰好一次。

### 错题本

```text
GET /wrong-question?courseId=1&page=1&size=10
```

page从1起，size最多50。返回题目、最近一次作答、参考答案、wrongCount、source、lastWrongTime，不返回deleted等实体字段。
错误提交使用数据库原子upsert，每次只增加一次；同题重复错误不增加行数。答对不改变已有错误次数。
手动收藏仅标manual，首次收藏wrongCount为0，已存在记录的错误次数保持不变。

### 工具助手

```text
POST /agent/chat
{"courseId":1,"question":"我上次这门课错在哪？请查最近30天记录。"}
```

工具：searchCourseMaterial、readAnswerRecords、saveWrongQuestion。courseId由服务器绑定，模型不能通过参数换课程。
只有用户明确要求收藏/记下时才允许保存工具；保存也校验题目确属绑定课程。调用次数最多4次，工具错误如实返回。
返回answer、sessionId、toolCalls、references，能看到工具名、参数和结果；最终回答另有日志。不输出模型内部思考。
分数、错题次数和先后顺序直接按真实记录组织，避免模型把倒序历史说反；返回最近一次作答的遗漏要点。历史工具最多20条、题干200字、答案1000字预览。检索工具的解释复用严格引用答疑，不把模型额外举的例子冒充课件内容。
工具接口与严格引用答疑分开：`/qa/ask`用于基于课件回答，`/agent/chat`用于执行查询记录或收藏等任务。

### 多轮会话

```text
POST /session       {"courseId":1}
GET /session
DELETE /session/{sessionId}
```

创建返回sessionId；之后给`/qa/ask`或`/agent/chat`传sessionId。课程从会话继承，不能在同会话切换课程。
Redis只保存最近6轮完整成功的问答，TTL为7天；新建/列表/删除均可用。无sessionId的答疑不会访问会话历史。
有历史且问题含指代时，模型只返回代词对应的对象名称；名称必须出现于历史中。服务器替换对应片段，保留其余文字，避免模型把“词素”改成“词法单元”。接口返回rewrittenQuestion并记录日志。会话处理锁防止同一会话并发交错，异常轮次不进入历史；正常拒答仍是一轮完整回复。

## 验收与证据

```powershell
node scripts/verify-stage2.cjs --phase=qa
node scripts/verify-stage2.cjs --phase=generate
node scripts/verify-stage2.cjs --phase=answers
node scripts/verify-stage2.cjs --phase=tools
node scripts/verify-stage2.cjs --phase=sessions
```

该脚本会调用真实模型并创建验收题/答题记录，只用于本机课程资料。状态在被Git忽略的data/evidence/stage2-state.json，固定requestId避免中断重跑重复计错。已通过的阶段自动跳过；加`--force`可重验，开始重验即清除该阶段旧通过标记，失败不会沿用旧结果。
不要并行运行两个该验收脚本。真实输出和失败记录保存在eval/stage2-results.json；四条最终问答实录在eval/qa-samples.md。
第一批验收暴露错误评分要点和引用不完整，记录已备份后仅逻辑隔离本次脚本数据，失败证据保留；没有删除上传资料或清空数据库。

单元测试覆盖：无效模型JSON不入库、来源不在候选中、独立复核拒绝、局部得分、证据不在用户答案、requestId重放及冲突、选择题零模型调用、手动收藏不加计数、空检索零回答调用、工具写入条件。真实Redis测试覆盖六轮窗口、锁不被其他请求释放、课程绑定及删除。
最终结果以eval证据和测试报告为准，不能只看“编译成功”。

最终验收入口：[第二段验收报告](../eval/stage2-summary.md)。数学符号比较仍可能被模型混淆并触发拒答，固定15题中的失败不会因更换会话验收例子而删除。自动选择题第一版仅支持判断式二选一，题目可读性和简答评分要点仍需学习者复核。
